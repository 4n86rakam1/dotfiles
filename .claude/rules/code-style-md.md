# Markdown の書き方

## 構造

1 次元の列挙は箇条書きで書き、テーブルは行と列の 2 軸が実際に意味を持つときだけ使う。見出し・ネスト・空行は、読み手が構造をたどるのに要る分だけ使う。箇条書きの項目間には空行を入れない。

## フォーマット

- 括弧は常に半角 `()` を使う。全角括弧 `（）` は使わない。
- フェンスコードブロックには言語識別子を必ず指定する (例: ` ```bash `)。不明な場合は ` ```text `。
- 太字・イタリックは多用しない。強調が本当に必要な場合のみ使う。
- 順序付き/順序なしリストは、並列な離散項目またはユーザーがリストを明示要求した場合のみ使う。
- `---` は見出しで十分な場合は使わない。
- 日本語文中の英字の前後には半角スペースをつける。

## 文章形式

2 文以上の説明は段落形式で書き、過度に短い箇条書きのシリーズにしない。

## markdownlint ルール

遵守: MD031 (コードブロック前後の空行)・MD034 (URL は `[text](url)` または `<url>` 形式)・MD040 (コードブロックに言語指定)・MD060 (テーブルの `|` 前後スペース)。無効化済み (従わなくてよい): MD013・MD024・MD033。

編集後は以下で確認する。

```bash
markdownlint --config ~/.markdownlint.yaml <対象ファイル>
```
