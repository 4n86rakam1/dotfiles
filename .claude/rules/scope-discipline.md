# Scope Discipline

Implement only what was asked. Never do the following without checking first:

- Creating or committing an ADR, a design document, or a plan file (`docs/plans/*`, `PLAN.md`, and the like)
- Editing `.gitignore` (`~/.gitignore_global` already covers `CLAUDE.local.md` and friends)
- Editing files outside the request, refactoring adjacent code, tidying dependencies, or reformatting

When an addition looks warranted, propose it in one line and wait.
